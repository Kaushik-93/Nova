# Demo data

An outdoor-goods retailer, split across two sources the way a real company's
data is. Generated by `generate.py`; rebuild it with `make seed`.

| Source | Connect as | Contents |
|---|---|---|
| Postgres, database `shop`, schema `shop` | `nova_ro` | `regions`, `products`, `customers`, `orders`, `order_items`, `refunds` |
| MySQL, database `marketing` | `nova_ro` | `channels`, `campaigns`, `ad_spend_daily` |

## How the sources join

| Shop | Marketing | Notes |
|---|---|---|
| `orders.utm_campaign` | `campaigns.campaign_code` | Needs `UPPER(REPLACE(utm_campaign, '-', '_'))`. About 97% of tagged orders match; the rest carry junk tags such as `(not set)`. |
| `regions.region_code` | `campaigns.target_region_code` | Same format. `NULL` on the marketing side means a global campaign. |
| month of `orders.order_ts` | month of `ad_spend_daily.spend_date` | No key needed for monthly comparisons, but see the time zone trap below. |

## Traps the profiler should find

These are deliberate. Each one changes a number if it's missed.

| Trap | Where | What to do |
|---|---|---|
| Soft deletes | `orders.deleted_at` | Exclude rows where it is set. |
| Test rows | `customers.is_test`, emails at `nova-test.example` | Exclude their orders. They are huge (12–49 units of the priciest product), so they noticeably inflate revenue. |
| Cancelled orders | `orders.status = 'cancelled'` | Not revenue. |
| Refunds | `refunds`, `orders.status = 'refunded'` | Partial refunds leave the status as `delivered`, so the status alone understates refunds. |
| Cents vs dollars | `*_cents` in shop, `*_usd` in marketing | Divide shop money by 100 before comparing. |
| Duplicated keys | `ad_spend_daily` | About 2% of campaign-days have a restated second row. Filter `is_latest = 1` or spend is double counted. |
| Non-unique emails | `customers.email` | Count customers by `customer_id`. |
| Undeclared foreign keys | `order_items` | No FK to `orders` or `products`; infer them. |
| Time zones | `orders.order_ts` is UTC, `spend_date` is America/Los_Angeles | Month boundaries differ by hours between sources. |
| Sample skew | `ad_spend_daily` has no TikTok before 2025 | Spend steps up in January 2025. |

## Prompt-injection fixtures

Product 17's `description` and the column comment on `shop.products.description`
contain text that tries to give instructions to an AI agent. They are test
fixtures for the harness, which must treat them as data. Don't remove them.

## Why the numbers don't move

Each day has its own random generator keyed on the date, so later days never
affect earlier ones. Reseeding next year adds rows but leaves Q2 2026 unchanged,
which is what lets the evals assert exact numbers. Only the last few days' order
statuses and any refunds not yet due depend on when you seed.
